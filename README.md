# Konten Instagram ExtraCourse

Tempat transit media untuk Metricool. File diakses lewat GitHub Pages:
`https://extracoursead.github.io/konten/<folder>/<file>`

## Alur
1. Simpan media final di `YYYY-MM/` (nama: `YYYY-MM-DD-judul.png/mp4`), commit, push.
2. Tunggu Pages selesai (±1 menit), lalu jadwalkan di Metricool memakai link di atas.
3. Metricool langsung menyalin file ke servernya sendiri (`static.metricool.com`),
   jadi setelah posting terjadwal, file besar (video) boleh dihapus dari repo ini.
4. Jika riwayat repo mulai besar, riwayat boleh dikosongkan (repo ini hanya berisi media).

Template sumber desain ada di `_template/`.
